
# Mi Ruta Dev

Programa personal de aprendizaje de Web Development y Mobile Development.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- React
- React Native
- Expo
- Git y GitHub

## Fuentes de aprendizaje

- Udemy
- HolaMundo
- ITLA

## Horario

- Lunes a miércoles: 9:00 AM - 4:00 PM
- Jueves y viernes: 12:00 PM - 4:00 PM

## Funcionalidades

- Horario interactivo.
- Ruta de aprendizaje de 16 semanas.
- Checklist semanal.
- Seguimiento de progreso.
- Almacenamiento local del progreso.
- Diseño responsive.

## Instalación

Descargar el proyecto y abrir `index.html` en un navegador.

No requiere dependencias ni instalación de frameworks.
